# SkySignal

SkySignal is a weather-focused prototype for checking local conditions and sample forecasts for selected South African cities.

## Run locally

```powershell
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Important

Weather values and alerts in this prototype are illustrative sample data. The app is not connected to a live forecast provider and does not send notifications. For current weather warnings, consult the [South African Weather Service](https://www.weathersa.co.za/) and local authorities.
